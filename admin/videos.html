Ver site

Esta secção existe só aqui no admin — não aparece no menu do site público. Os vídeos são descobertos pelos visitantes dentro dos móveis, dos projetos e do destaque na home.

Para publicar um vídeo: 1) faça o upload do ficheiro para o Cloudflare Stream (dashboard da Cloudflare, ou pelo telemóvel via cloudflarestream.com) e copie o UID do vídeo; 2) cole esse UID aqui em baixo. (Também aceita um link direto do YouTube/Vimeo, se preferir usar isso em vez do Cloudflare Stream.)
